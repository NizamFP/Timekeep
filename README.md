# Timekeep

Intinya website buat timekeeping acara. Satu page dipake sama timekeeper, dan satu page lainnya buat didisplay di TV/display apapun yang mengarah ke pengisi acara

## Fiturz

-   Display waktu (obviously)
-   Warna semakin mencekam mendekati waktu habis
-   Menghitung durasi overtimenya, apabila udah habis alokasi durasinya

## Tutorial Install

1.  Buka repository ini di github
2.  Klik **Code** (kanan atas, tombol warna hijau)
3.  Klik **Download ZIP**.
4.  Extract zip filenya

## Tutorial Make

-   Pake layar atmin buat nyetel durasinya
-   Buka `display.html` di TV/layar buat memperlihatkan waktunya ke pengisi acara
-   Buka `index.html` di layar macbook pribadi
-   Pastiin settingan share screennya **Extended Display**
-   Kontrol timernya pake tombol **start**, **pause**, dan **reset**

## Tampilan
-   lebih dari 1 menit -> `menit:detik` (contoh, `2:35`)
-   <1 menit  -> detik aja (contoh, `59`, `8`)
-   Countdown selesai -> `Time's Up`
-   Setelah countdown selesai -> Label overtime and durasi overtime (contoh, `1:06`)
-   Durasi overtime dihitung semenjak countdown selesai
